# VistaRoom Product Overview

## Feature X Summary

Feature X lets a user preview a room layout before committing to a purchase. The architecture
for Feature X separates rendering from data fetching so the preview stays responsive on slow
connections.

## Non-Goals

This overview does not cover billing or authentication — those are documented separately and are
out of scope for any architecture note about Feature X.
